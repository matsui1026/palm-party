# PALM PARTY（てのひらパーティ）

スマホのブラウザで遊べるミニゲーム集です。3本のアクションゲームが入っていて、1台のスマホでふたり対戦もできます。インストールもビルドも不要です（HTML / Canvas / Web Audio のみ）。

## ゲーム

| ゲーム | 内容 | 操作 |
| --- | --- | --- |
| **コインダッシュ** | 3レーンを走ってコインを集めるエンドレスランナー。壁はよけて、柵はジャンプ。マグネットとシールドのアイテムあり | 左右スワイプでレーン移動、上スワイプか中央タップでジャンプ |
| **ぐるぐるスネーク** | 体で囲んだ敵をつかまえて長くなる。1回でたくさん囲むほどコンボ倍率アップ。赤いトゲトゲに当たると縮む。制限時間60秒 | ドラッグした方向に進む |
| **ゲートぐんだん** | 2つのゲートからどちらかを選んで仲間を増やしたり武器を強くしたりしながら、敵の群れを撃ってボスを倒す | 左右ドラッグで移動（射撃は自動） |

## ふたりモード

トップ画面で「ふたりで」を選び、スマホを机に置いて向かい合わせで遊びます。手前が **P1（青）**、向こう側が **P2（オレンジ）** です。

- **コインダッシュ / ゲートぐんだん**: 画面を上下に分け、P2側は上下反転して表示。ふたりとも同じコース（同じシード）でスコアを競います。ゲートぐんだんは3ステージ勝負です
- **ぐるぐるスネーク**: ひとつのフィールドを共有する陣取り対戦。相手の頭を囲む「ハント」で相手を縮められます。画面の上半分に触れるとP2、下半分はP1の操作になります

PCではキーボードでも遊べます: P1 = 矢印キー、P2 = WASD、Esc で一時停止。

## ローカルで動かす

```bash
python -m http.server 8124
```

`http://localhost:8124` を開きます（`index.html` を直接開いても動きます）。

## 構成

- `index.html`, `css/style.css` メニュー・リザルト画面
- `js/core.js` 乱数、効果音（Web Audio で合成）、描画ヘルパー、パーティクル
- `js/main.js` 画面遷移、1P / 2P 画面わけ / 2P 共有フィールドのレイアウト、タッチ・キー入力の振り分け
- `js/games/runner.js` コインダッシュ
- `js/games/snake.js` ぐるぐるスネーク
- `js/games/gate.js` ゲートぐんだん

ゲームを増やすときは、`PP.register({ id, name, howto, layout2P, create })` で登録し、`update / draw / pointer / key / scores` と `done` を持つクラスを返します。
